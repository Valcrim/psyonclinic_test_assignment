# Как запустить
1. Установите Docker
2. Создайте файл ```.env``` в корне проекта
3. В ```.env``` файл добавьте переменную по образцу с ```.env.example```
4. Замените заглушку на действительный ключ
5. В папке с проектом запускаете команду 
```docker compose up --build```

Эндпоинты для тестирования доступны на странице:
http://localhost:8000/api/docs
